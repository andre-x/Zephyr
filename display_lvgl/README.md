# Zephyr ESP8684 LVGL OLED Project

This project uses the **LVGL** on an ESP32-C2 and OLED display (128x64). 
It is based on the official **Zephyr** LVGL sample.

## Hardware
- **Board:** ESP8684-DevKitM-1 v1.1
- **Display:** 0.96-inch SSD1306 OLED (I2C)
- **OS:** Zephyr RTOS (v4.4.99)

## Wiring
- **SDA:** GPIO 2
- **SCL:** GPIO 3
- **Power:** 3.3V

## Requirements
To build this project, you must have a working Zephyr development environment. 
If you haven't set it up yet, follow the [Zephyr Getting Started Guide](https://docs.zephyrproject.org/latest/develop/getting_started/index.html).
